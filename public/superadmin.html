How invites work
1. Create a user with email and phone number
2. Invite email sent instantly with secure link to set password
3. User clicks link, sets password, logged in to their portal immediately
4. Expired invites can be resent — a new secure link is generated
5. Phone saved for SMS-based self-service password reset via Twilio
